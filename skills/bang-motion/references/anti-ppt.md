# Anti-slide checks

Bang Motion starts from a recurring failure: technically valid animation can still feel like a presentation. Motion needs actions, changing attention and a world the viewer can follow.

## Failures and repairs

| Failure | Repair |
| --- | --- |
| Kicker, headline, subtitle, body and four badges | Keep one short statement and one main object for a promo. Explainers can add one meaningful world label. |
| Three claims displayed as three default tiles | Demonstrate one feature, transform an object, swap a word, shuffle a stack or use another concept-led feature presentation. |
| Three or more full scenes switched only by opacity | Preserve a subject or connected world. Let an action or reveal carry the change. Live cartoon stages can use cuts. |
| A photo and sentence per beat | Build evidence and causal relationships with three to five purposeful objects where useful. |
| Slow photo scaling is the only motion | Add depth, active subject or a meaningful change of shot size. |
| Every cut gets the same zoom, flash or spin | Use restrained cuts, overlapping choreography, a brand mask or an object-led transition. Reserve a special effect for one payoff. |
| Every project is dark with particles | Choose a surface from the brand and subject. Light editorial, paper, poster, pastel and flat cartoon are all valid. |
| Every background uses horizontal streaks | Use moving gradients, slow geometry, living texture, light or parallax. Streaks belong to speed or flow subjects. |
| Text competes with bright particles or bloom | Make a quiet text pocket. Reduce local detail and brightness. Glow belongs on objects. |
| All headlines are centered capitals with the same stagger | Vary size, position and entrance. Prefer sentence case and intentional emphasis. |
| A pill and sparkle highlight every phrase | Choose one optional emphasis method per piece, derived from the brand. Pauses or word order can be enough. |
| App UI is just a screenshot zoom | Assemble and use a real task, then show its result. Follow important interactions with the camera. |
| Tiny cursor click in a full dashboard | Anticipate the click with closer framing, hold while it happens, then move toward the result. |
| Camera pan exposes a black world edge | Overscan the world and clamp framing. Short offsets stay within the scene's actual coverage. |
| Wide cartoon map with tiny houses and empty ground | Divide it into frame-sized stages. Keep characters readable at the widest shot. |
| New brand uses the previous film's structure and colors | Propose three concepts and record the fingerprint before authoring. Compare structure as well as styling. |
| Text vanishes only in export | Remove filters from text and every text-bearing ancestor. Use opacity and transforms. Check an actual export when authorized. |
| Autonomous embedded footage or doubled soundtrack | Use native Media/Audio owners and the editor clock. Preserve one intended audible source. |

## Scene checks

1. Is the main action clear within about 0.2 seconds?
2. Does the viewer carry a subject, motif or world across the boundary?
3. Does each new piece of information produce a relevant visual response?
4. Are there at most two levels of explanatory text? A document with up to three short lines can count as a visual object if it is actually evidence, not hidden body copy.
5. If text disappears, does the action still convey something? Is the background calm enough to support it?
6. Does camera movement mean emphasis, discovery or comparison? Do not force a move when the character action already tells the story.
7. Have entrances and exits got different rhythms? Starting ranges: enter in 0.7 to 1.3 seconds, exit in 0.35 to 0.55. Short bumpers can be faster.
8. Are expensive effects saved for one or two special moments?
9. Can a viewer read the title before attention moves again? Reduce words before reducing font size.
10. At a segment boundary, do the outgoing and incoming states form the intended continuous action without a gap?

Cartoon stages are a deliberate exception to a single traversable collage: each stage has a complete living environment and can cut to the next place. They are not static cards with fades.

Inspect actual pixels with Subclip contact sheets and exact frames. Code review can find repeated fades, tiny type and clock errors; it cannot prove a frame works visually.

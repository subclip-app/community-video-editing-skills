# Asset prompts

Common line for every prompt: `Photorealistic commercial photography, consistent lighting, no text, no logo.`

| Asset | Prompt idea |
|---|---|
| Hero product on white | The product only, centered, soft shadow, three-quarter view, exactly like the attached product photo |
| Before state | The same product or the problem state, same angle and light |
| After state | The same product in its improved state, same angle and light |
| Character sheet | Full body, neutral pose, plain background, front and side, outfit and one memorable detail |
| Empty location | The place with nobody in it, wide, the film's light and time of day |
| Hero machine or key object | A clean, well lit view of the object that drives the story |

## Rules

- Attach the real product photo as a reference to every asset that shows the product.
- Keep all assets in one lighting family.
- Never ask for letters or numbers on assets.
- Review each asset at full size before you accept it.

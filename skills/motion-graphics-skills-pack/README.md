# Motion graphics skills pack for Subclip

<!-- cli:start -->
> Install from your terminal: `npx @subclip/community-skills install motion-graphics-skills-pack`
<!-- cli:end -->

Fifteen recipes for launch-grade motion graphics where every frame is code. You describe the piece; your agent builds an editable layer on the Subclip timeline. No screen recording, no video model, no credits.

What you can ask for:

- **Set up once:** a brand notes file and a motion notes file that every later piece reads first (01), a brief writer (02), an 8-part prompt (03) and a reference breakdown (04).
- **Make:** a Mac-style launch film with a growing notch (06), a looping chart with exact data (08), a milestone number built from thousands of points (09), a 3D night-street title opener (11), a loop cover (14).
- **Sixteen premium effects (10):** button to player, search to results, card to workspace, tabs to panels, chart morph, dashboard zoom, spring stack, magnetic dock, masked type, elastic type, text to layout, image reveal, perspective shift, glass focus, flowing paths, particle logo.
- **Compare and ship:** a three-model showdown (12), a newsletter promo (13) and a 9:16 reel export with a safe-zone hook (15).
- **Already covered elsewhere:** the launch video (05) points to `product-launch-motion`, the Vox explainer (07) points to `vox-explainer`.

Every recipe has its own reference file in `references/` (exact brief with [brackets], Subclip tools, checks) and its own short clip in `examples/`. A 20 second capability reel shows eight of them. The overlap check against the other community skills is in `references/overlap.md`.

## Try it

> Set up my brand for motion. My colors are #153592 and #26c9d5, the font is Inter.

> Build the chart morph effect with these six numbers, square, in my brand.

> Make a milestone video for 12,431 followers. Here is my dashboard screenshot.

> Make my newsletter cover a looping GIF where only the lighthouse beam moves.

## Notes

- Everything runs as HyperFrames layers (or Remotion on request) inside Subclip. Nothing is installed on your machine and no key is asked for.
- Numbers and facts on screen come from you, with a source. Sample data is labelled "Illustrative data" or "example".
- The reference clips are rough: they show each style, they are not pixel copies of anyone's work.
- Four recipes are new to the library (06, 09, 10, 14), nine are partly new, two are pointers. The upstream README says 13 skills; the repository actually contains 15 skill folders and all are handled here.

# Prompt building blocks

## Paper-cut still

```
Recreate this image as a handmade torn paper collage.
Every shape is a separate piece of paper with rough torn white edges and visible fibers.
Soft shadows where layers overlap, flat color with a light grain, no gradients.
Keep the same composition, subject and colors as the reference.
Plain, slightly textured background. No text.
```

## Storyboard sheet

```
One image, a 3 by 3 grid of nine equal panels, read left to right and top to bottom.
The same torn paper scene, same camera in every panel.
Panel 1 is the empty background. Each next panel adds more paper pieces.
Panel 9 is the finished scene, identical to the reference.
Thin neutral gutters between panels. No numbers, no text.
```

## Animation

```
The scene builds itself out of torn paper, following the nine panels in order.
Pieces slide in, flip and settle with a small paper overshoot. No hands, no tools.
Fixed camera. Paper rustle and soft taps as pieces land.
<optional single end action, or: holds on the finished scene>
```

## Reading the result

| Problem | Fix |
|---|---|
| Pieces look like clean vector shapes | Add more about torn edges and fibers in the still, regenerate the still first |
| Sheet panels differ from the still | Attach the still again and regenerate the sheet |
| Pieces teleport in | Say how each piece moves in and name the order again |
| Extra objects appear | Add "only the pieces shown in the sheet" |

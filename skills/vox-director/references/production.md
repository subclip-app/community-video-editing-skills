# Production recipes

## B-roll and audio

Use the creator's approved generator route. In Subclip, make posters with `generate_ai_media`. The upstream poster and photo-edit family is Nano Banana 2. Select that family or its current Nano Banana 2.1 equivalent with the required image reference support. For the upstream GPT Image edit fallback, use the current GPT Image option with reference support. Compare a single frame first and reuse the approved anchor as a reference on compatible shots.

The upstream living-poster and video-edit choice is Gemini Omni Flash. Use Subclip's Gemini Omni 1.1 Flash when available. For a first-frame animation, pass the exact poster as a `start_frame` source when supported. Omni chooses its own duration and emits audio automatically. Quote the automatic duration policy and mute the visual's sound with `update_media_item` when the narration owns playback. The upstream alternate for authorized people and branded imagery is Kling O3 Pro. If the exact model is absent, choose a supported Kling 3 image-to-video option for its first-frame control, or use native motion to preserve the source artwork. Respect catalog content restrictions and any rejection. For any other missing model, report the actual replacement before generating.

Use `update_media_item` and `trim_media_item` to fit shots to their windows. Use `add_media_keyframe` for an editable flat push, pan or pullback. If a shot comes up short, use the matching still, an earlier cut or a detail insert. Use native `add_text_overlay` and `update_text_item` for exact headlines and keep them separate from captions.

Choose voice by language, then accent and energy. Prefer the upstream xAI TTS voice if the live catalog offers it. Otherwise use a matching approved voice, for example Gemini TTS with a measured documentary delivery, and keep it consistent. Offer `get_voice_samples` unless choice is approved or delegated. Save the choice with `set_approved_voice`, use `generate_speech`, then `import_speech_to_timeline`. For requested, permitted voice matching, use the built-in saved or offline clone workflow if available. The upstream Seed Audio speaker-reference recipe has no documented equivalent in the current built-in speech workflow. Reuse creator-supplied speech when a specific voice is essential.

Use the upstream MiniMax Music 2.6 through `generate_music` with instrumental settings when the creator requests a new bed. Import it into its own lane and use `update_audio_item` for fades and level changes under speech. Check the opening, a dense speech passage and the ending with playback when available.

## A-roll from a recorded presenter

Keep the original performance and its continuous audio on the timeline. Use timed words to mark overlays and cutaways at natural clause breaks. Place the speaker in a paper frame or use a muted, source-aligned duplicate for a photographic sticker. To isolate that duplicate, follow Subclip's background-removal skill with `remove_media_background` after the cloud scope is approved. Import onto the duplicate by `replaceItemId`. The video result already receives a color key. Preserve the base recording. Review the hair, face, hands and gesture continuity, and verify a single audible source.

If the creator explicitly wants a generated restyle of the speaker's surroundings, use Gemini Omni 1.1 Flash with the supported `source_video` input only for a separate, explicitly approved short source clip that meets the model limit. A timeline trim alone does not limit the Omni generation upload in the checked implementation. Use the native composite for long footage or exact performance. Compare the take against the original timing and mouth shapes before using it. Keep the original audio only if sync holds throughout the take. A generated restyle cannot guarantee frame-for-frame performance.

## C-roll from a photo

Keep the original photo visible as a photographic sticker. Use a cropped duplicate or local-only `remove_media_background` on an expendable duplicate where the silhouette needs isolation. Use separate paper, shadows and props around it. Scope dots and grain to the background. For a portrait paper doll, lock the outfit and give gestures to the illustrated body. For a product, lock the silhouette, reflections and label. If a reference edit is used, direct it to change only the world, then compare the face or label against the original. Native compositing with a separate original cutout is the reliable path when those pixels matter. Keep a headline out of the C-roll poster where it competes with captions.

## Speaking host with a separate world

Build a world plate with clear space for the host and a presenter plate with a steady camera. Test left or right placement in 16:9 and a lower placement in 9:16. Leave room for captions. Use a matching greenscreen look from `list_ai_avatars` or an approved portrait if the selected model supports it. The upstream speaker model is Seedance 2.0 with a narration reference. Use it only if the live catalog exposes the required portrait and audio reference workflow. Otherwise use Subclip's portrait-plus-speech avatar route, such as Avatar IV, for the same two-plate edit. Use `generate_ai_media` with the model-supported portrait or avatar look and the exact speech as `audio_reference` when supported.

Keep both cameras locked and pin the shape of each world element. Prefer one host shot per beat. Keep the beat short and use actual speech duration and the catalog's limits. Verify both plates before animating the world. Animate it with native motion for a predictable background, or use the approved Omni model when its aspect fits. For a clean green plate, use `list_element_catalog` and `add_media_effect` with the registered color key parameters. For a non-keyable background, use the background-removal workflow or retain the host as a framed insert. Keep one synced audible track. Use the host output's speech if the model retimed it and that output passes playback review. Never time-stretch a synced host shot. Check the mouth, cut edges, color spill and the voice transition into nearby beats.

## Piece-by-piece hero assembly

Plan a backdrop and independent clean assets for each moving piece. Keep the landing positions from the approved poster. Fill the holes where pieces were removed with clean matching paper. For a quick focus reveal, use a locally softened, non-text background patch under the landing area to avoid a sharp ghost copy. Keep the end frame faithful to the approved arrangement.

For simple movement, keep each asset as a native media item and keyframe its position, scale and rotation. Try an off-screen arrival with a short overshoot, a drop with a settle, or an in-place focus pop from about 135% scale. Use small sway once settled. Save a palette-matched burst or confetti accent for the payoff. Keep overscan for moves that would expose canvas edges. Compare frames before entrance, at impact and after settlement.

For a composed hero scene, use the built-in HyperFrames skill and `validate_runtime_layer_source` before `add_runtime_layer`. Use Remotion for an explicit request, existing Remotion layer or selected template. Import assets into the project first and use the returned asset URLs. Use one bounded layer per scene, deterministic time and native text/audio where practical. Keep the unused canvas transparent. Check forward and backward seeks. For changes, use `read_layer_source` and `edit_layer_source` with its source hash, or `update_runtime_layer` for a full replacement. Author the choreographed scene from the individual assets. The source's one-pass poster slicing and automatic reconstruction have no equivalent single editor operation in this workflow.

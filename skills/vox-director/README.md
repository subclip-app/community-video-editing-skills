# Vox director

<!-- cli:start -->
> Install from your terminal: `npx @subclip/community-skills install vox-director`
<!-- cli:end -->

Direct the shots for a paper-collage explainer. Map the narration into beats, compare looks for the same shot, then plan where to cut from the whole scene to a telling detail. Apply the plan to a topic, a recorded presenter, a single photo or selected digital-host beats.

> Turn my existing narration into a 30-second vertical collage. Show me the beat map and three looks for the opening shot. Keep the lettering on my product photo intact.

Use this skill for storyboards, coverage, styling and motion direction. Use [Vox explainer](https://github.com/subclip-app/community-video-editing-skills/tree/main/skills/vox-explainer) for the full topic-to-film workflow. In a shared project, carry this skill's approved beat map and shot windows into Vox explainer's production stages.

- [Beat and shot design](references/beat-layer.md)
- [Themes and prompt recipes](references/prompt-guide.md)
- [Presenter, photo and layered motion recipes](references/production.md)

# Consistency check (stage 9)

Run before any clip is made. Compare the script, the storyboard image and the three sheets. Report pass, fix needed or not checked for each line. Say what you actually looked at; do not claim a check you did not run.

## Character
- Same face and identity in every panel
- Same hairstyle, apparent age and body type
- Same outfit unless the script changes it
- Same accessories

## Product
- Same shape, proportions, colors, materials and finish
- Same logo and branding, same controls
- Product visible and used in the way the script says

## Location
- Same layout, architecture and major objects
- Same light direction and time of day
- No second room appearing without a reason

## Story
- Hook in the first 1 to 3 seconds
- Sequence matches the script and spoken lines
- Soft call to action at the end
- No claim that the product cannot back up

## UGC format
- Every shot 9:16, phone point of view
- Natural creator feel, no cinema polish, no drone, crane or gimbal move
- Text overlays match the script and sit inside the safe zone

## Assets
- Four separate images: character sheet, product sheet, location sheet, storyboard
- None contains another asset. If one does, regenerate only that one

## Consent and disclosure
- Character is fictional or a consenting creator
- AI disclosure line ready if the platform asks

When it passes, ask whether to go to the clip plan. When it fails, name the single smallest fix and repeat the check for it only.

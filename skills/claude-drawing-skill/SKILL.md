# Claude Drawing

Build a still, a staged drawing, or a short character action from deliberately placed marks. Use only the requested motion. Drawing geometry, paint passes, and timing are authored in the layer source and use zero Subclip AI credits. The core workflow needs no generator choice. If the creator separately asks for generated media, load the relevant Subclip generation skill for creator CLI options, live estimates and approval before paid work.

## Read the project

1. Load the installed Subclip video editor, motion graphics and HyperFrames skills. Use their current tool schemas and HyperFrames authoring contract. For explicit Remotion, React or TSX requests, a selected Remotion template, or an existing Remotion layer, load Subclip's Remotion skill instead and drive the same SVG marks from the current frame. Use one explicit project ID throughout. Start with `get_project_outline`, then `read_project_section` for the affected lanes and timing. Read the director brief with `get_project_director_brief` and resolve exact IDs and media URLs with `list_editor_assets`.
2. When artwork responds to existing media, read `get_media_context` before frame extraction or transcription. Request `includeContactSheet: true` and reuse existing transcripts. Inspect up to six specific points with `fileId` and `inspectAtSeconds` before widening the analysis. For files missing context, use `list_media_without_context`. In an editing run, use `generate_media_context`, inspect its results, and save observed descriptions with `describe_media`. For attached video, use the manifest's `originalPath` when importing, never its storyboard directory. Keep the original video out of prompt payloads.
3. Honor the project ratio or the creator's requested ratio. Default to 16:9 for a new standalone drawing film. Read the proposed insertion frame with `view_current_frame` using `timeSeconds`. Use `get_timeline_contact_sheet` across the beat to find clear space and check faces, captions and important action. If narration drives the piece, place the narration first and use the real audio item boundaries as the beat clock. Follow the installed editor skill for naming a new empty project.

## Draw the scene

1. Decide what the drawing explains, its focus, the palette, the amount of empty paper, and where exact labels can sit. Sketch small silhouettes. Lay out far, middle, subject and foreground in that order. Choose one or two accents. Read [art direction and style recipes](references/art-direction.md) for the medium and its failure modes.
2. Write editable SVG groups for silhouettes, outlines, wash masks, texture and accents. For dense paint, use Canvas as part of a HyperFrames composition and precompute the marks once from a fixed seed. Reserve grain for the surface or stroke that needs it. Keep different ink passes, paper pieces and subject parts named in source. Use a transparent backdrop for an overlay. Paint paper only where the composition calls for it.
3. Use one short layer per drawing beat. For a static drawing, show the completed art throughout. For a draw-on, add cumulative passes, or reveal a stroke along its own length. Keep motion such as a moving pen or a dropped paper cutout as a separate, time-driven action. Build one finished hold for the viewer to read. Use [the SVG recipe](references/svg-draw-on.md) and the installed runtime contract. Seed random marks once. Make the state at a timestamp independent of the preceding frames.
4. Validate the complete composition with `validate_runtime_layer_source` using the selected `kind` and matching binding type. This call has no project ID. For HyperFrames send `variables` if needed, and for Remotion send `props`. Correct all validation errors before placement.

## Place and review

1. Call `add_runtime_layer` with the project ID, `kind`, `name`, `source`, `startTime`, `duration`, and matching `intrinsicWidth` and `intrinsicHeight`. Supply the smallest useful centered rectangle with `x`, `y`, `width`, and `height` as canvas percentages. Use full-frame bounds only for an explicitly full-frame drawing. Match the authored duration to the item duration, including the last hold. Keep any real media and audio on native lanes. If the drawing needs a media texture or matte, import the asset through the matching native import workflow and bind the exact URL returned by `list_editor_assets`.
2. Serialize timeline writes and reread the affected state after each coherent edit. Use the returned layer ID for revisions. Read the relevant lines with `read_layer_source`, then patch with `edit_layer_source` using `expectedSourceHash`. Reserve `update_runtime_layer` for a full replacement or an item timing or geometry change. Keep existing manual edits. If the creator needs exact titles or labels, check the contact sheet across their time range and add them with `add_text_overlay` as separate static items. Confirm the revised layering on representative frames.
3. Inspect `view_current_frame` near the start, midway through the reveal, during the accent and in the final hold. Jump backward and forward and confirm the same time produces the same result. Check adjoining cuts for gaps or unintended overlaps. Look for accidental shapes, noisy grain, clipped marks, and color or detail that steals focus. Review and fix the biggest issue first, typically over two to four passes. For a new standalone piece, use `set_project_duration` to end at the last intentional beat. For an existing cut, preserve its duration unless the request changes it.
4. Record the palette, seed, beat timing, inspected frames and any unresolved checks with `update_project_director_brief` and `write_session_summary`. Export video only on request. Read the installed Subclip export skill and use `get_export_configuration`, `list_render_queue`, then `export_video` if there is no duplicate. Omit range fields for the full video. External clients can track the request with `get_export_status`. If requested, use `export_current_frame` for a still PNG at the requested `timeSeconds`.

Each authored scene is editable as one runtime layer. For marks that need independent timeline placement, make separately timed runtime items or use native Elements for simple geometry.

## Reference

A finished example: [three-drawings-reference.mp4](examples/three-drawings-reference.mp4). Three HyperFrames layers, each one canvas or SVG drawing seeked from its own clock. Ink wash (7 s): far, middle and near ridges painted as opaque washes that fade into mist, dry brush strokes along the slope, moss dots and pines, then a vermilion kite and seal as the one accent. Continuous line (6 s): the gold sprout stroke from the [SVG recipe](references/svg-draw-on.md) drawn by a moving pen, a light travel arc, a sun loop and green leaf fills. Paper collage (6.5 s): torn paper hills with white fiber edges drop in far to near under one light, two striped balloons rise and crayon birds finish the hold. Labels are static text items, and paper, pencil and stroke sounds sit on native audio lanes. The [contact sheet](examples/one-second-contact-sheet.jpg) shows one frame per second. Zero AI credits.

# Abstract

No literal objects need to be readable at once: show the story through motion. Use springs for liquid, a seeded flow field for generative. Cap element counts so the layer previews smoothly.

Each recipe below is a short build brief. The example clip named in the title is the visual target: open it before building. The chai film (kettle pours into a clay cup, steam rises, 5 s) is the demo story; replace it with the creator's story using `our-guide.md`.

## 87 Liquid motion

- Example: `examples/87-liquid-motion.mp4`
- Look: Smooth, bouncy, glossy shapes that stretch and settle like liquid.
- Palette: Gradient fills, soft highlights, one strong accent
- Motion rules: Spring easing, squash and stretch, blobs merge with a goo filter.
- Typography: Rounded sans for a title.
- Engine: HyperFrames (SVG with goo filter)
- Best for: Brand intros, fintech, wellness, transitions
- Also see: motion-polish

## 89 Generative abstract

- Example: `examples/89-generative-abstract.mp4`
- Look: Thousands of tiny strokes in a flow field that form the kettle, pour and cup.
- Palette: Dark ground, strokes in 3 to 4 hues
- Motion rules: A seeded flow field moves thousands of strokes that settle into shapes; no Math.random.
- Typography: None.
- Engine: HyperFrames (canvas)
- Best for: Art pieces, music, tech backdrops
- Also see: ai-style-atlas 84

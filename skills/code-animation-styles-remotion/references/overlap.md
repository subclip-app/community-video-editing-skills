# Overlap with other community skills

The upstream collection has 39 styles. Many looks already exist in other Subclip community skills, which were written for editable layers and sometimes have deeper recipes. The 39 stay indexed here because creators ask for this set by name and because each one has a ready example clip. When two skills cover a look, use the rules below.

## Which skill wins

- Need the look shown in the example clip, a chai style retell, or a quick style test: use this skill.
- Need a deep workflow for one technique (paper collage from an image, isometric figure, pixel effects, 3D scene, SVG rig, ink-line cartoon acting, maths animation): use the specialist skill listed below and read only the style recipe here for palette and motion hints.
- Need a look from a catalog of prompt recipes for AI image or video generation: use `ai-style-atlas`, `ai-illustration-styles` or `wan-animation-styles`. They spend credits; this skill does not.
- Never load two skills for the same layer. Pick one, name it to the creator, and keep to its rules.

## Not overlapping on purpose

`code-motion-styles` has its own 16 prompt files (stickman notebook, cel-anime launch, brick world, circuit board and others). The recipes here are different builds of the same looks, so do not merge them. If a creator names a prompt from that skill, use that skill.

# Scene pack

One per scene.

```
SCENE <n>  <start> to <end>  <chapter>
Narration: <the words the narrator says in this scene>
Attach: <asset IDs>
Video prompt:
  <look line: format, lens, light, color>
  0-8s:  <shot>. Camera: <move>.
  8-16s: <shot>. ...
  16-24s: <shot>. ...
  Sound: <room tone, footsteps, score>. No voice.
```

## Asset prompts

| Asset | What to ask for |
|---|---|
| Character | Full body, neutral pose, plain background, clothing and one memorable detail |
| Location | Empty, wide, golden or night light as the film needs, no people, no text |
| Prop | Isolated, clean, three-quarter view |
| Map view (investigation) | Dark background, thin route lines, no place labels (add labels as native text) |

## Pacing

- A 30 second clip carries 3 to 5 shots. Do not squeeze more.
- Narration is about 2.3 words a second, with pauses at chapter breaks.
- End each chapter on an image that raises the next question.

# Skeleton progression ad

A "what happens if you do X" countdown, from day 1 to day 365, told with a skeleton or a body model that changes at each milestone.

## Steps

1. State the habit or product use in one line and choose 4 to 6 milestones (day 1, day 7, day 30, day 90, day 365).
2. Lock the skeleton character in one picture, plain and well lit.
3. One picture per milestone showing a visible change in the same pose and camera.
4. Short clips that move between milestones (a slow push, a turn).
5. Native text for each milestone, set with `add_text_overlay` so the day count is always exact.
6. End card with the product photo and call to action.

Rules: only show changes the creator can support. Mark the video as illustrative when it implies a result.

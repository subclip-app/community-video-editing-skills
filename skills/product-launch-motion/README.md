# Product launch motion

Make a Dribbble-level product launch film from code inside Subclip. The idea: one shape that never cuts, morphing through your product's states while a cursor drives every change, springs give the motion weight, text swaps with a short blur, and every move lands on a beat.

The skill carries the original author's creative direction and a style index of 68 entries: 15 scene types, 11 one-shape UI states, 3 flourishes, 8 motion recipes, 10 easings, 9 motion-grammar rules, 5 camera and cursor moves, 5 look and grade recipes, a sound cue table and a three-directions method. Each entry has its own prompt file and its own 10 second reference clip, made in code with a fictional product.

## How it works in Subclip

1. Give it a product (URL, description or screenshots). It asks for the states, palette and a track, or you say "director picks".
2. It writes three directions, kills two, plans scenes on a beat grid and shows the plan.
3. It builds each scene as an editable HyperFrames or Remotion layer, with music or local voice, captions if there is speech, and export.
4. It samples frames from the exported file, measures loudness and reports its decisions.

Code layers cost no credits. Anything paid (music, AI media) is quoted first and waits for your yes.

## Folder

- `SKILL.md`: the direction and workflow.
- `references/style-index.md`: all 68 entries with their prompt files and clips.
- `references/styles/`: one prompt file per entry.
- `references/subclip-pipeline.md`, `layer-code.md`, `voiceover-led.md`, `overlap.md`.
- `examples/`: one 10 second reference clip per entry and the capability reel.

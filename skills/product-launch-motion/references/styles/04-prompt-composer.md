# 04 Prompt and composer

Group: Scene types (shots)
Use it for: First product act for anything with an input: search, chat, CLI, form.

## Recipe (in our own words, swap the [brackets])

- One wide centred card: field, placeholder, caret, primary button, gradient focus ring showing a 3 px rim.
- Cursor arrives, presses, ring lights, placeholder fades. Type the exact sentence a real user would type with one snapped-index tween.
- Cursor moves to the button; the fill wipes in from the left and the label swaps at 12 percent fill.
- A run panel opens and its steps complete on their own beats. Leave the last step running so the next shot can finish it.
- One click sound per press, no per-keystroke sound.

## Prompt to give the layer builder

Build a [10 s] [1920x1080] layer for [fictional or real product, brand colours]. Style: Prompt and composer. Follow the recipe above. Copy and numbers: [your approved copy and figures]. Hold the final state still for the last [0.5 s]. Use only seekable motion: every value is a function of the playhead.

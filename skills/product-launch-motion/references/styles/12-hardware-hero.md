# 12 Hardware hero

Group: Scene types (shots)
Use it for: A physical object reveal. Use it once per film.

## Recipe (in our own words, swap the [brackets])

- CSS 3D plane stack or a Remotion Three layer: outer dolly, inner turn, soft contact shadow, rim light.
- The object arrives already turning and decelerates into its hero angle. A rim light sweeps the edge on the adjective.
- Callouts are flat 2D labels with leader lines. An exploded view must reassemble. Hold dead still 0.5 s on the hero angle.
- Check the brightest frame at full size for bloom over white.

## Prompt to give the layer builder

Build a [10 s] [1920x1080] layer for [fictional or real product, brand colours]. Style: Hardware hero. Follow the recipe above. Copy and numbers: [your approved copy and figures]. Hold the final state still for the last [0.5 s]. Use only seekable motion: every value is a function of the playhead.

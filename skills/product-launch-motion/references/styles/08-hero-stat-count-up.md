# 08 Hero stat count-up

Group: Scene types (shots)
Use it for: One approved number and what it means. Never use a number you cannot source.

## Recipe (in our own words, swap the [brackets])

- Fixed-width tabular-nums numeral box, small-caps label, one scaffolding bar.
- Start the count on the label word, run it linear (ease none), end on the word that completes the phrase. Grow with scale, never font-size.
- Hold with one bounded sine settle of 2 px or less. Second figure: dock the first in 0.34 s, retire the bar, land the second.
- Camera: a 2.5 percent dolly on a wrapper.

# 10 Comparison columns

Group: Scene types (shots)
Use it for: Crowded categories and replacement sells. Name your product, describe the rest by category.

## Recipe (in our own words, swap the [brackets])

- Row labels in the buyer language, three columns: partial coverage, the manual way (a different mark shape), yours (accent check, highlight band).
- Scaffold first, then one column per clause. Mark stagger 0.1, 0.15, then 0.24 s so it builds to the payoff.
- Your column flips from one driver: rotateX -90 to 0 in 0.12 s. Table arrives turned 6.5 degrees and squares up.
- Never strike through or cross out the alternative.

## Prompt to give the layer builder

Build a [10 s] [1920x1080] layer for [fictional or real product, brand colours]. Style: Comparison columns. Follow the recipe above. Copy and numbers: [your approved copy and figures]. Hold the final state still for the last [0.5 s]. Use only seekable motion: every value is a function of the playhead.

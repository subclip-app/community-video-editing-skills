# 13 Terminal and dev tool

Group: Scene types (shots)
Use it for: One command and the thing exists. SDKs, CLIs, agents.

## Recipe (in our own words, swap the [brackets])

- Rebuild the terminal, do not screen-record it. Mono type at 22 to 28 px on 1920 wide.
- Typewriter is one snapped-index tween with ease none. Output rows are pre-laid out and revealed in bursts, never on a metronome.
- A determinate bar, never a spinner. The exit code line is the last thing to move.
- Copy real output and trim it; never invent flags.

# Block prompt pattern

Use this shape for each 10 second block. Replace the angle brackets with real content.

```
<style key line>

0-3s: <subject and action>. Camera: <move>. Light: <note>.
3-6s: <subject and action>. Camera: <move>. Light: <note>.
6-10s: <subject and action>. Camera: <move>. Light: <note>.

Sound: <room tone, impacts, music bed>. No spoken voice.
```

## Rules of thumb

- One clear action per shot. Two actions in one shot is where models drift.
- Name every attached sheet in the prompt by what it shows, in the order attached, so the model knows which is which.
- Put the reveal (the twist) in block 2 and the mechanism in blocks 2 and 3. The kicker is the last 2 seconds of block 3.
- The first block should make the myth feel believable and a little ordinary. The flip works better against a calm setup.
- If two blocks must share a location, attach the same location sheet to both.

## Beat map for the narration

| Beat | Block | Seconds | Job |
|---|---|---|---|
| Myth | 1 | 0 to 8 | State the belief while the picture agrees with it |
| Twist | 1 to 2 | 8 to 14 | One sentence, one visual break |
| Mechanism | 2 to 3 | 14 to 26 | Show the true cause in motion |
| Kicker | 3 | 26 to 30 | One line the viewer repeats later |

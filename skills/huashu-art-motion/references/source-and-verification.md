# Source and verification notes

## Provenance

Source: https://github.com/alchaincyf/huashu-art-motion by alchaincyf. The supplied source SKILL.md identifies version 1.3.1. Source code and documents carry MIT. The original LICENSE is included unchanged, including its copyright notice.

The upstream README adds explicit exceptions for Huashu's character art, its appearances in overview images and demonstrations, and Clawd fan-demo media. Those assets are not copied. The Arphic-derived stroke data and bundled fonts have separate licenses and are also omitted. No demo videos, engine code, scripts, third-party fonts or character frames are distributed here. The cover is original SVG artwork for this adaptation.

The source credits Tak's Art History Speedrun for the fixed-room mechanism and original girl/cat premise. This package uses the design method without distributing those frames, sound or composition. Reference-channel names identify studied methods, not affiliation or an included template.

The adaptation retains the reference-breakdown method, frame-first routes, 53 style recipe summaries, nine explainer grammars, material/shape separation, fixed-scene and long-scroll mechanisms, character quality checks, camera punctuation, palette examples, musical motif and beat-grid ideas, and evidence-based review. Model-identity gating, private provider setup, shell assembly, automatic repository update checks, promotional routing and mandatory multi-agent review are omitted. The methods can be followed by a single agent in Claude Code, Codex, Cursor or Subclip's in-app agent.

## Feature limits and alternatives

| Upstream operation | Current supported alternative or limit |
| --- | --- |
| Frame-difference heatmaps, fitted beat grid and objective motion gates | Inspect existing context and targeted frames; use saved-state checks, playback and supplied beat markers. No dedicated matching analysis tool was identified. |
| Batch green-screen keying and sprite slicing | Generate transparent poses when supported, use separate imported poses, or crop an atlas inside an authored runtime scene. No dedicated batch operation is promised. |
| Exact synthesized score with instrument changes on every era boundary | Import creator-supplied music or generate through `generate_music`, then align native edits to the actual audio. Generation cannot guarantee exact score/onsets. |
| General character modeling, rigging, cloth physics and exact lip sync | Use approved pose assets, native imported animation or the relevant supported avatar workflow. Device 3D tools do not establish these character capabilities. |
| Source render, delivery and QA scripts | Validated short runtime layers, native timeline assembly, frame/playback review and requested native export. No equivalent numerical QA score is claimed. |

The core workflow needs no new app feature. Full parity with upstream numerical QA and batch asset processing would need additional dedicated operations.

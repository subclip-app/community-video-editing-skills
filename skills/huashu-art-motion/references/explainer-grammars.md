# Nine explainer grammars

Select by the sentence's job, not by a famous channel name. Use at most two complementary grammars in a normal short film while keeping one art direction. These are authored scene designs for Subclip, not the upstream executable clip-spec engine. A short beat is one editable runtime item; longer explanations need several focused segments with explicit continuity.

## 1. Mathematical transformation

Use when the narration describes one object becoming another: pixels become a vector, a vector becomes activations, weights change a signal. Write down "what becomes what" for every beat. If there is no transformable object, select a different grammar.

Start with the actual object, coordinate system or curve, then introduce the question or formula. Keep no more than two explanatory statements at once. One semantic color means one concept across shapes and formulas, with at most about four active concept colors. A black background with restrained saturated line colors is a useful source example, not a required theme.

Transform a shape over about 1 to 3 seconds, then hold for understanding. A smooth quintic curve `6u^5 - 15u^4 + 10u^3` gives zero speed and acceleration at the ends. Match point counts, direction and start points before path morphing. Stagger related elements lightly rather than dropping everything simultaneously. Use linear progression for a stroke being written.

The camera moves to a new object, then holds. No ornamental drift during explanation. Keep formula symbols tied to the same visible objects and colors. In narration-led Subclip work, align the transform to the spoken action verb. The source channel's animation-first production history does not override the imported narration clock.

## 2. Product and interface reveal

Use for a product, feature, comparison or important specification. Let the actual screenshot, recording or product output dominate. A useful target is about 80 percent of landscape width or 90 percent in portrait. Recompose for the aspect ratio.

One name, number or feature carries the shot. On a real interface, move to the unreadable detail over about 0.9 s, then hold; a reveal can use a faster accent. Pull back or move sideways afterward. Do not repeatedly center a tiny glass card over a large glow background.

Prefer restrained spring-like settles with little or no overshoot. Land a number when it is spoken; begin the count early enough to reach it then. Keep digits tabular so their width does not shake. A repeated number stays at its value instead of counting from zero again.

Brand colors come from the product. Glows, glass, gradient text, blur entrances and floating cards are optional treatments, not five defaults to combine. In Subclip, text/ancestors must not use CSS blur/filter, even at zero. Use opacity and transforms for text. For actual rotating device shots, use native 3D layers.

## 3. Data chart

Use for real numbers, dates, comparisons and changes. Write one conclusion for the chart before drawing it. Values, units and sources must agree with narration and remain exact. Say whether a number grew to or grew by a value. Bars start at zero; disclose any justified axis exception rather than using motion to distort scale.

Build axes, reveal each relevant series when named, then annotate only the conclusion. Highlight one series while secondary ones turn gray. Keep the chart in the film's world and palette; a white report page inside a dark painted film needs deliberate context.

Allow at least a short hold after values settle. Use roughly one second for a clear data transition as a starting point. Keep the camera still while data grows. Do not repeat the identical chart layout three times; use a detail, real evidence or a larger comparison when the story calls for it.

Use a runtime graphic with explicit data values for exact drawing. Neither a generated chart image nor this skill's sample data is evidence. No automatic data acquisition is implied.

## 4. Layered science world

Use for a system that can be explored at several scales: environment, organism, mechanism, particle. Organize depth into background, action plane and foreground. Use clear silhouettes, a consistent shadow family and purposeful environmental cycles.

Plan a scale transition around a specific object. Compute how far a portal or circle must grow to cover the frame, with margin; arbitrary scale values leave corner gaps. Keep the destination subject visible within the opening. Inspect the actual peak of the transition, not its first frame.

Let background life stay subordinate while the mechanism performs. Labels identify only what matters at the current scale. Material and palette remain coherent through zoom levels. A flat illustrative scene is not automatically a faithful recreation of a specific studio or channel.

## 5. Evidence collage

Use for real sources, quotations, documents, photographs and relationships. Import licensed or creator-owned evidence first. Set up objects, their relations and the camera before adding paper grain, tape or decoration.

Arrange a shared investigative desk. At rest the current evidence should occupy most of the view. Glide between connected items, push only to read a detail and pull out to explain the relationship. A red string can guide attention only when it expresses a real link.

A new paper may enter with a quick slap or controlled paper turn; keep incoming content opaque enough to avoid doubled text. Match position/scale for a shared-element cut. Use native text for quotations and exact figures. Footage and evidence remain native items where practical, with runtime graphics for inseparable desk choreography.

## 6. Continuous whiteboard

Use for a mechanism, process or relation that benefits from accumulated marks. Treat the board as one large space and the current camera view as a window into it. Segment the timeline at explanation beats and reproduce the already drawn board state explicitly in each segment.

Draw in meaningful order: subject, connection, consequence. Bring the camera into position as the first stroke starts. Within a section, synchronize marks to spoken verbs. Do not turn every sentence into a new title plus bullet list.

Use rigid corners for rectangles; generic smooth splines can bulge them into ovals. Reserve the caption band in camera space, including during zooms. Reading time starts when the last list item finishes drawing, not when the first stroke begins. Leave that hold in the voice/beat plan.

## 7. Storytime performance

Use for a concrete personal event, causal sequence or comic reversal. Pose, gaze, contact and reaction carry meaning. Hold a readable composition, then hard-cut to a reaction or new size. Use a whip only when the sudden change is itself the joke.

Prefer creator-supplied or generated finished poses. Original semantic SVG is appropriate only for an explicitly chosen flat cartoon direction with actual character design. A few blinking circles are not a performance. Align feet, preserve body scale, and show a real hand grip.

Do not dissolve between incompatible silhouettes and create a double-headed person. A pose cut plus a small settle often works better. Time the anticipation, action and reaction separately. Keep scene changes driven by the story rather than an arbitrary two-second metronome.

## 8. Kinetic type with evidence

Use when spoken stress, slogans or a musical sequence make typography the subject. Pick a shared beat table. Put the main word on a strong beat and smaller supporting objects on subdivisions. A real object or evidence action should accompany the phrase so the film is more than changing words.

An upstream example used a 120 BPM four-bar pattern: main word, evidence object, supporting sentence, evidence action, highlighted word, then space or exit. Reuse the idea of a recurring rhythm, while varying layout and density. Preserve reading time; do not assume one rapid flash communicates a sentence.

Use native text and authorized text keyframes where they express the motion. Use a short runtime composition for tightly coordinated line layout or object/type choreography. Keep words editable in source, exact and clear of captions. Avoid a single long text-only runtime film. Kinetic motion is intrinsic here, but not permission to animate ordinary labels elsewhere.

## 9. Presenter-led explainer

Use when an original presenter meaningfully connects evidence, charts and emotional reactions. Plan several arrangements: side explanation, full-frame number, comparison, presenter inside a chart, reaction close-up. A fixed person-left/chart-right layout for the entire film stays monotonous.

Prepare both full-body and bust views if needed. A seated pose needs a seated asset. Establish position and scale explicitly at each segment start. Match standing height by feet, not by arbitrary image bounds.

Tie mouth changes to actual speech intervals and stop on pauses. This is not automatic lip sync; exact talking animation requires the appropriate approved avatar workflow and actual inputs. Keep body action and chart values on the same narration clock. A number must settle before its emphasis circle; do not show "over" or "+" while counting through lower values.

The source's ninth grammar was a reference implementation without a ready parameterized clip or supplied character library. This adaptation does not invent one. Build and inspect a small scene before extending it.

## Choose and hand off

For each segment, record the grammar, time range, physical event, visible data, text, asset IDs, camera and hold. Validate source through the native runtime tools. Inspect entry, settled content, action peak and exit, then adjacent cuts. Preserve the same medium and palette when combining grammars.
